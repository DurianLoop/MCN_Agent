说明
这是一道贴近 AOI 部门真实工作的轻量实操题。请你围绕一个 MCN 商单 brief，自己去小红书寻找适合的博主，参考其公开内容风格，完成 达人筛选、内容参考、脚本产出、分镜设计、飞书文档接入。希望看到你能把真实业务流程拆小，并用 AI 工具做出可复用交付。请全程使用你最擅长的 AI产品实现。
提交物
1. GitHub 仓库链接，包含报告、参考资料、Prompt/工作流、Skill、飞书接入说明。
2. 一份最终报告，说明你怎么找博主、怎么参考内容、怎么设计脚本和分镜。
3. 一个可复用 Skill，建议放在 skills/mcn-script-assistant/SKILL.md。
4. 一个飞书文档链接或截图，最终脚本需要由程序、工作流或自动化方式写入飞书文档。
题目：小红书达人调研 + 商单脚本生成助手
客户 Brief
• 品牌：轻食酸奶「轻醒」。
• 产品：0 蔗糖高蛋白希腊酸奶，口味包含原味、蓝莓、黄桃。
• 主要卖点：高蛋白、饱腹感、低负担，适合早餐、运动后、下午茶。
• 目标人群：22-35 岁城市女性，关注健身、控糖、轻食和上班族效率生活。
• 投放平台：小红书短视频；希望内容自然种草，不要硬广，要符合原博主创作风格。
• 注意：不能承诺减肥、治疗、降糖等功效；避免夸大效果；脚本需要适合真实达人拍摄。
你需要完成
A. 小红书博主调研
1. 在小红书自行寻找 2-3 位适合该 brief 的博主。
2. 记录每位博主的主页链接或截图、内容方向、粉丝画像判断、近期 2-3 条代表内容。
3. 选择 1 位适合的博主，并说明选择理由：人设、内容场景、表达方式、品牌匹配度。
4. 整理参考文稿或内容拆解，需要说明你参考了哪些结构、钩子、镜头或表达方式。
B. AI 工作流与 Skill 设计
1. 设计一个 4-6 步流程Agent， brief 拆解 -> 内容风格模仿 -> 脚本生成 -> 风险质检 -> 写入飞书文档。
2. 提交核心 Prompt，说明输入、输出格式、约束条件和质检规则。
3. 沉淀一个可复用 Skill。Skill 至少包含：适用场景、输入材料、执行步骤、输出格式、风险检查清单。
C. 脚本、分镜与飞书文档接入
1. 基于最终选择的 1 位博主，产出 1 条符合博主过往内容的短视频脚本。
2. 脚本需包含：标题/开头钩子、口播文案、产品植入点、结尾 CTA、合规风险提醒。预期是该博主可直接根据脚本推进录制。
3. 根据博主视频提供分镜设计，包含画面、口播/字幕。
4. 将最终脚本直接写入飞书文档，并在 README 中说明接入方式。
5. 提交飞书文档链接或截图。仅手动复制粘贴不作为完整接入方案，需要说明自动化写入飞书过程。

评分标准
• 业务理解（15%）：是否理解 MCN 商单脚本交付，而不是只生成泛泛文案。
• 调研质量（15%）：小红书博主选择是否合理，参考内容是否有依据，是否避免照搬。
• AI 工作流与 Skill（45/%）：Prompt 是否清晰，Skill 是否可用，流程是否有质检和兜底，内容产出质量如何。
• 交付完整度（25%）：脚本、分镜、参考材料、GitHub、飞书文档接入是否完整可复现。
