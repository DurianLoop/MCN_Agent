# 合规风险质检

| 检查项 | 结论 | 说明 | 处理 |
| --- | --- | --- | --- |
| 减肥/瘦身承诺 | 通过 | 脚本未出现“减肥”“掉秤”“瘦”等表达 | 保持现状 |
| 治疗/降糖承诺 | 通过 | 仅表达“0 蔗糖”产品属性，未承诺降糖或控血糖效果 | 上线前核对包装信息 |
| 绝对化表达 | 通过 | 未出现“最好”“一定”“保证”等绝对表达 | 保持现状 |
| 代餐暗示 | 通过 | 脚本调整为下午茶/运动后加餐，不暗示替代正餐 | 避免写“代餐”“一杯顶一餐” |
| 高蛋白表述 | 低风险 | 使用“蛋白质比较高”，需以产品真实营养成分为准 | 上线前核对营养成分表 |
| 饱腹感表述 | 低风险 | “有饱腹感”是体验表达，未承诺时长和效果 | 不追加“饱一上午”等承诺 |
| 硬广感 | 通过 | 产品从沉浸式酸奶碗制作自然进入，CTA 为评论想看的颜色/口味 | 保持视觉系美食语气 |
| 拍摄可执行性 | 通过 | 场景为桌面、白碗、勺子、酸奶、水果和燕麦，符合达人沉浸式美食拍摄条件 | 保持低布景成本 |

## 禁用表达清单

- 减脂神器
- 吃了不胖
- 降糖
- 控血糖
- 治疗
- 替代正餐
- 一杯顶一餐
- 保证瘦
- 无负担随便吃

## 推荐替代表达

- “0 蔗糖配方”
- “蛋白质比较高”
- “口感更厚”
- “适合早餐、运动后或下午茶”
- “吃起来有饱腹感”
- “比临时买甜饮更符合我的加餐习惯”
- “视觉系酸奶碗”
- “蓝莓/黄桃颜色层”
- “适合下午茶或运动后加餐”
